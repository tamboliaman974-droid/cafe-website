# Brew & Bite Café Website

A responsive 3-page website for a small café, built as a portfolio project.

## Features
- Responsive layout using Bootstrap 4 (works on mobile, tablet, desktop)
- Home page with hero section, about, customer favourites and reviews
- Menu page with tables and a live search filter
- Contact page with a table reservation form and JavaScript validation
- Custom CSS theme using CSS variables

## Built With
- HTML5
- CSS3
- Bootstrap 4.5
- JavaScript (vanilla)

## Project Structure
```
├── index.html      # Home page
├── menu.html       # Menu with search
├── contact.html    # Reservation form
├── styles.css      # Custom styles
├── script.js       # Search + form validation
└── README.md
```

## Run Locally
1. Download or clone this repository.
2. Open `index.html` in any browser.

No installation needed.
